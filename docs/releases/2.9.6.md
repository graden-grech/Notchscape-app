# Notchscape 2.9.6

Public candidate: build330, Apple silicon, macOS15 or later. Native Liquid Glass
uses macOS26 or later with standard-material/accessibility fallbacks. This
release remains Apple Development signed, not notarized.

## Interface and features

- Native Settings sidebar search, visible page titles, standard sidebar control,
  clearer hover/press feedback and a simpler Appearance page.
- Original music artwork/control arrangement restored in the idle state;
  Mirror and Settings buttons use full-size native glass surfaces.
- Regular-sized Workspace Tools controls, correctly proportioned Dock icons,
  focused Dock layout options and shorter Settings explanations.
- Optional Dock Bar/Workspace/widgets, desktop snow and Home snow caps,
  additional landmark themes, display compatibility and local workspace tools
  from the locally tested preview series. Features remain optional; the Add-ons
  catalog does not claim that separate downloadable modules already exist.

## Public and local boundaries

Accounts remain off and no app account is needed. The public app explicitly
disables Face Unlock and excludes its device-bound service, provisioning
profile and recognition weights. Camera-preview source notices remain bundled.
Existing Face Unlock preferences and encrypted data are not deleted. The
maintainer's separately signed local331 preview keeps the Face companion; it
is not a generally distributable customer build.
