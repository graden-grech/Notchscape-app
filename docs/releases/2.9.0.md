# Notchscape 2.9.0 — Workspace, capture and appearance tools

This release brings the local feature preview to the public app and includes
the 2.8.5 AI chat-name fix. Existing settings, private local data, app/helper
signing identity, HUD permissions and update key are preserved. No account is
required; account features and cloud sync remain disabled.

## New tools

- Commands search (app-local Shift–Command–K), native Tools menu, local calculator, unit/date conversions, encrypted snippets, named Quicklinks and saved color swatches/formats.
- Stopwatch/laps, work–break focus cycles, timed Keep Awake and a pinned calendar-event countdown.
- Capture Studio with image markup, flattened redaction, explicit searchable capture library, QR/barcode recognition, silent screen recording, trimming and MP4/M4A/GIF export.
- Window positioning with Undo, saved workspace layouts, and an app/window switcher with optional one-shot previews. Window control requires Accessibility; capture/previews use Apple's consent controls.
- Preferred audio-output order, input-device selection, supported hardware microphone mute and opt-in accessory low-battery alerts. Hardware support varies; unavailable controls remain unavailable.
- Additional watched download folders, a floating pinned note window, Finder Services for file actions, and foreground Apple Shortcuts actions.
- Network throughput, available disk activity and memory-pressure information in the optional System page.
- Saved appearance editor, preview/import/export/Undo, optional scene details and six new palette scenes: Spring Bloom, Summer Coast, Night Sky, Botanical, Desert Dusk and Graphite.
- Feature catalogue with individual module controls and privacy/resource descriptions.

## Privacy and limits

New capture, library, routing and alert actions are explicit/opt-in. Recording
is silent and requires the user to choose a source with Apple's picker; no
camera/microphone recording or hidden background capture is added. Recordings
are bounded and stop on lock, Presentation Mode or closing Capture Studio.
Conversions create new files rather than overwriting originals. Private tools
hide or stop while locked/presenting. Theme files contain data, not executable
code, and custom URLs only open safe app surfaces.

A real music Up Next queue is not available through the current player
connections; the app says so instead of inventing a queue. Existing seasonal
photos/icons remain; the six new themes are static palette/vector scenes, not
new photorealistic backgrounds or automatic seasonal schedules.

## Compatibility and verification

Apple silicon; macOS 14 or later. Integrated screen recording requires macOS 15;
native Liquid Glass requires macOS 26. Development-signed with the existing
identity and Sparkle key, **not notarized**. Automated policy/fixture tests,
signed builds, public download/feed checks, hosted CI and real updater/HUD
checks are separate validation steps, not interchangeable guarantees.

Remaining coverage includes other macOS versions, physical-notch/DisplayLink
hardware, fresh-device permission flows, VoiceOver/contrast/window-size matrix,
audio-device/low-battery hardware, multi-display window-workspace restoration,
long focus/sleep-wake cycles, Finder Services/Shortcuts registration, and the
full capture/export/appearance-import matrix. See
`docs/FEATURE_IMPLEMENTATION_TRACKER.md` for feature-level verification details.
