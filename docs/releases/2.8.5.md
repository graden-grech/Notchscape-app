# Notchscape 2.8.5 — AI chat names

- AI activities show the matching chat name instead of `/` or a working-folder label when local title metadata is available.
- Clicking the compact AI activity reveals its chat title, with a readable fallback when a provider has not supplied one.
- Title lookups stay on this Mac, match the exact session, run off the UI thread, and never modify agent data. Short-lived caching avoids repeated disk reads during tool bursts.
- Preserves existing preferences, HUD permissions, signing identity, and automatic-update trust. Accounts remain disabled.

This focused update does not include the larger in-progress workspace-tools,
capture, window-management or theme feature batch.

Requires Apple silicon and macOS 14 or later; native Liquid Glass requires
macOS 26. Development-signed with the existing identity and Sparkle key; not
notarized. Local chat-title fixtures, real Codex title lookup, signed-build
identity checks, and live HUD checks are verified separately from public
download, hosted CI and a real Sparkle update/relaunch. Other hardware and macOS
versions and fresh-device permission/onboarding flows remain unverified.
