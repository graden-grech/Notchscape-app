# boringNotch Custom 2.8.3

- Adds bounded HUD recovery after launch, activation, and wake without a permanent watchdog.
- Checks the actual enabled media-key event tap and run-loop source instead of treating an allocated tap as working.
- Adds Restart HUD and a clear inactive-interceptor message. Opening HUD settings retries the interceptor, and closing Settings no longer stops permission monitoring while HUD replacement is enabled.
- Cleans up stale event taps and respects cancellation and the user's HUD on/off choice during recovery.
- Matches the Home battery capsule to the neighboring Mirror and Settings controls' 30-point height and native glass treatment. Small native on/off switches remain unchanged.
- Adds a signed-build identity gate, a read-only live HUD smoke test, and documented release checks to catch signing and runtime regressions.

Apple silicon, macOS 14 or later; native Liquid Glass requires macOS 26 or later.
Uses the existing Apple Development signing identity, bundle identifier, installed app path, and Sparkle update key. Development-signed; not notarized.

Local policy/helper checks, signing identity checks, cold-launch and Restart HUD tests passed for the recovery implementation. Live updater/relaunch validation is reported separately after publication. Full sleep/wake, permission-revocation, VoiceOver, and external-display/DisplayLink testing remain pending; macOS permission approval cannot be bypassed or guaranteed permanently by the app.
