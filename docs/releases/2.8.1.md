# boringNotch Custom 2.8.1

This update adds display styles and seasonal customization, improves AI status handling, and reduces unnecessary redraws.

- Choose Dynamic Island or Notch for displays without a physical notch in Settings → General. Dynamic Island fits inside the menu bar.
- Choose System, Autumn, Halloween, or Christmas in Settings → Appearance. Seasonal themes use matching control colors and app icons.
- Christmas adds a full-size decorated tree beside the Home calendar, with space reserved so the calendar keeps its normal size.
- The standard runtime and in-app icons now use the same artwork as the installed app.
- Adds sports league and favorite-team selection, compact inline scores, and score notifications.
- AI usage warnings with remaining capacity stay active. Exhausted usage shows a brief red indicator, and a trailing Stop event cannot replace that failure with a green completion check.
- Uses darker purple for Codex and orange for Claude Code.
- Reduces AI hook redraw frequency, removes the repeating provider pulse, and pauses music/lyrics timers when playback is paused.
- Replaces layered custom glass effects with native Liquid Glass on macOS 26, with lightweight material fallbacks on older systems.
- Removes the oversized Settings Quit button; Quit remains in the menu bar menu.

## Requirements and validation

Apple silicon Mac, macOS 14 or later. Native Liquid Glass requires macOS 26 or later.

The Release build and update archive are signed. Display-style switching, seasonal Home decorations, and AI quota-failure handling were checked locally. Physical-notch hardware, DisplayLink hardware, and the complete HUD restart/permission regression remain pending. This build is developer-signed and is not notarized.
