# Notchscape 2.9.5 — local preview checks

Signed build 308 is installed and locally checked. Build 305 remains the
recoverable pre-Dock checkpoint. None of these previews has been published.
Public 2.9.3/2.9.4 archives and the update feed are unchanged.

- Face Unlock's protected-helper connection now joins the user's session.
  The installed app passes the harmless “Protected storage is ready” check.
  Explicit enrollment and recognition tests now open a guided camera sheet,
  with a mirrored oval preview and progress ring. Automatic lock scans do not
  display frames. Real authentication, enrollment and unlocking remain human
  tests; RGB recognition is not Apple Face ID.
- Settings adds an Add-ons Store with Features, Theme Packs and Installed
  views. It clearly distinguishes currently bundled features, unpublished
  downloads and the local-only Face preview. This is a catalog and trust-policy
  foundation; real downloaded code/resources have not been separated from the
  current app. The separately downloadable Dock and WidgetKit add-ons are still planned;
  the later bundled Dock workspace increment is described below.
- Christmas and White House Christmas add a static Settings trim. Theme accents
  color sidebar icons, with an always-multicolor override. System retains the
  original per-section colors. All expanded menus share the theme backdrop;
  lower expanded corners are softer while physical-notch geometry is preserved.
- Windows adds 39 grouped placement actions, custom grids, controlled gaps,
  next/previous display, Undo and 42 unassigned optional shortcuts. It preserves
  the bounded, permission-gated AX path. No real user window was moved for tests.
- Clipboard adds local encrypted boards, type/date/pinned filters, loose matching
  and preview-and-copy text transforms. Best-effort sensitive detection hides
  matches; new sensitive copies expire after ten minutes. Legacy copies remain
  preserved. Recording stays off unless explicitly enabled.
- Thirteen optional menu readouts and an existing-tools menu start off. Fixed
  widths, shared sampling and lock/sleep/Presentation suspension are implemented.
  Visibility choices do not claim to download or remove package bytes.
- The installed app is shared at `/Applications/Notchscape.app`. Filesystem access
  checks pass for other local users, whose settings and privacy grants remain
  separate. Five obsolete old-name build products were moved to recoverable
  non-indexed storage; the old app-name Spotlight query is empty.

## Dock and Add-ons increment: installed build 308

The native Dock workspace adds explicit app/folder pins, saved reordering and
five cards: Clock, This Week, Battery, System and Now Playing. It starts off,
shares providers with Core, and does not replace the system Dock. Add-ons adds
search, feature details and clearer included/unpublished labels. These remain
bundled features; true separate downloads and WidgetKit are unfinished.

Live testing caught two defects before acceptance: build 306 refused an eligible
unlocked session when an optional lock key was absent, and build 307 entered an
adaptive-grid layout loop on repeated scrolling. The session correction retains
all public-session/user/lifecycle checks. Build 308 uses bounded eager rows and
fixed menu/card geometry. It passed 33,611 policy checks, strict native Swift 6
typechecking and 40 offscreen production-view scroll/layout passes, plus signed
identity/profile/branding/account gates with an unchanged 386-file source hash
snapshot. Installed build 308 passed eight alternating live scrolls with all five cards,
panel close/reopen and a real test-folder bookmark launch into Finder. Native
Add-ons/Details/glass spacing was reviewed. Three short process samples measured
0.0%, 0.2% and 1.7% CPU with about 90 MB memory. This bounded check is not a
complete performance or display/hardware matrix. HUD lifecycle checks and the
human physical-volume-key confirmation passed. No public updater test occurred.

Only the two temporary Dock settings were restored after the interrupted test;
all 51 allowlisted settings match the original snapshot exactly. Dock is off
after the test, matching its initial state. The verified
build 305 remains recoverable. See DOCK_WORKSPACE_PREVIEW.md and the current
local work checkpoint for the exact verification boundaries.
