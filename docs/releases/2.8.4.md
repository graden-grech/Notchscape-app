# boringNotch Custom 2.8.4

- No account required: setup offers **Continue Without an Account** and skips
  account setup. Account pages, sign-in, passkeys and cloud settings sync are
  disabled. Existing saved credentials and cloud settings are not deleted.
- A build/CI gate keeps unfinished account features disabled. The earlier
  optional account preview remains withdrawn from public downloads.
- The optional lock-screen Home dropdown shows only a lock symbol inside the
  expanded menu. There is no lock badge on the closed notch and no visible
  explanatory text. The normal Home menu returns after unlocking.
- External-display visibility can be turned off, with dependent controls clearly
  disabled. Saved display choices and local HUD permissions are preserved.
- Lighter Settings surfaces and a clearer terminal symbol for AI activity.

The lock-screen option remains experimental and off by default. It uses the
inherited private SkyLight integration, not an official Apple lock-screen
extension; behavior varies with macOS and hardware. The isolated lock view does
not contain normal calendar, Shelf, AI or account widgets.

Requires Apple silicon and macOS 14 or later; native Liquid Glass requires macOS
26 or later. Development-signed with the existing app/helper identity and Sparkle
key; not notarized. Existing preferences and the installed app path are retained.

Local signed-build, account-release-gate, policy and workflow/helper checks run
before publication. Public-download signature verification, GitHub CI and the
real Sparkle update/relaunch and HUD checks are reported separately. Fresh-device
onboarding, other macOS versions, full VoiceOver coverage, multiple external
displays/DisplayLink, rapid lock transitions and permission revocation remain
unverified. A successful compile or archive signature alone is not proof of a
live updater or media-key HUD test.
