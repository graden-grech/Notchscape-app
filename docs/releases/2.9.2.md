# Notchscape 2.9.2 (295) — Guided setup and White House themes

This release brings the White House theme and local preview refinements into a
new signed update. Earlier release archives and update-feed entries are retained.

## Changes

- Optional guided setup: six short chapters explain all 18 public Settings
  sections, with Back, Next, progress and Skip. New users can skip setup, and
  everyone can replay the tour from General settings or the Help menu.
- Related permission connections share one optional page. The tour itself
  changes no feature preferences and requests no access. Accounts remain disabled.
- Opening Calendar settings refreshes access status without prompting; Calendar
  and Reminders each have an explicit Connect action and current macOS purpose
  strings. Skipping setup no longer reopens old music-source setup on relaunch.
- White House has four rooms/views, neutral/red/blue décor and optional Christmas
  scenes: 24 distinct bundled photos, including snowy festive exteriors.
- Four matching White House icons: Republican, Democrat, and a Christmas version
  of each. Automatic matching follows style/Christmas; manual icons and custom
  accents remain independent. A hidden Dock icon stays hidden.
- Full-photo room/theme previews, aligned cards and a better Home panorama crop.
- Eight points of top clearance for expanded header controls, including Mirror,
  Settings and Battery, without increasing the closed notch or Home height.
- Weather starts off and Show on all displays starts on for new users. Explicit
  settings and older users' implicit defaults are preserved.
- Shared installation checks verify app files can be read/executed by other local
  users when installed in `/Applications`. Each person keeps separate settings,
  privacy grants and login startup. The unsigned installer preview is not shipped.

## Compatibility correction

Requires **Apple silicon and macOS 15 or later**. The linked media framework
already required macOS 15; the app/helper deployment targets, new update item,
archive gate and installer metadata now agree. macOS 14 installations are not
offered this release by Sparkle. Old releases/feed entries retain their original
metadata. Native Liquid Glass needs macOS 26; earlier supported systems use
standard materials.

## Distribution limits

The app uses its existing Apple Development signing identity and Sparkle update
key. It is **not Developer ID signed or notarized**, and is not claimed fully
production ready. The unsigned `.pkg` remains a local structural preview.
Other macOS versions/hardware, DisplayLink/external-display combinations,
fresh-account permissions and the full accessibility/performance matrix are not
fully verified. See [distribution readiness](../DISTRIBUTION_READINESS.md).

Original source/dependency notices remain in the Legal section. The White House
art is an independent architectural interpretation, with no official affiliation.
Artwork, exact prompts and source hashes are documented in
[the photo manifest](../WHITE_HOUSE_PHOTO_ARTWORK.md) and
[the icon manifest](../WHITE_HOUSE_ICON_ARTWORK.md).
