# Security Policy

## Reporting a Vulnerability

Security issues for Notchscape are handled by this repository's maintainer.

Please use [Report a vulnerability](https://github.com/graden-grech/Notchscape-app/security/advisories/new)
to send a private report to the Notchscape repository. Do not post exploit
details, credentials, private note content or personal screenshots in a public issue.

Include the app version, macOS version, affected feature and the minimum steps
needed to reproduce the issue. Remove secrets and unrelated personal data.
Response times and a release date are not guaranteed.

Report security bugs in third-party dependencies to the person or team maintaining the package or dependency.
